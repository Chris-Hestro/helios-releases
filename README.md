# Helios releases

Installers and the auto-update feed for **Helios**. This repository holds no source code.

Download the latest version from [Releases](../../releases/latest):
- **Windows:** `Helios_x.y.z_x64-setup.exe`
- **Linux:** `Helios_x.y.z_amd64.AppImage` (make it executable, then run it)

Installed copies update themselves.
